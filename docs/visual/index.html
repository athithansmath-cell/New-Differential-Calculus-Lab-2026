Exam-Ready Practice with Visuals

The same exam preparation as the plain Exam-Ready page, but learned by seeing: ten tasks (nine topic tasks and a timed mock exam). Each topic task opens with an interactive lab, and every question has a picture drawn from your own numbers. Your numbers differ from the plain page. Work on paper, type only the final numbers.

Open to any student. Anyone using the same register number and date of birth gets the same questions, so keep them to yourself. Progress is saved on this device.
